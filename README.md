# Equicy ($EQUICY)

Any agent. Any equity. Launch a coin on Stonk, pair it against a tokenized stock, an ETF, a pre-IPO token, a commodity, SOL or anything else, then plug in any AI agent. It gets its own wallet and goes to work. This is the same utility as STONCY, rebuilt as a retro desktop.

## Deploy
The site is a single `index.html` with no folders and no build step. Drop it into a GitHub repo or Vercel.

## Settings
Open `index.html` and find `CONFIG` near the top of the script:

```js
var CONFIG={xUrl:'',ca:'',buyUrl:'',chartUrl:''};
```

## Standout features
- **OS switcher:** reskins the whole site as Windows 3.1, Windows 95 or Mac OS 9 (Platinum windows and a top menu bar). The pick is remembered.
- **Desktop hero:** a Program Manager window with agent groups (double-click to build), a live analog clock, an agents.log feed and a readme in Notepad.
- **BUILD.EXE agent builder:** set the coin name, ticker, agent type, brain, pair and powers. It shows a live agent card and a boot log, then saves the agent as a preview slot on the visitor's device.
- **Mind loop:** MIND.EXE in an MS-DOS window steps through the 8-step loop with ASCII art.
- **Fee calculator:** a slider shows the split into credits, treasury, $EQUICY burn and agent upkeep, using the $20 / 50-50 to $100 / 15% rules.
- **Other sections:** agent slots, 8 agent types, 17 pairs, 17 powers, 12 brains, and $EQUICY buyback & burn with an hourly countdown.

Everything is pre-launch. Stats start at zero and builder agents are previews only.
